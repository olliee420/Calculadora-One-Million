# 📊 Calculadora One Million

Aplicación estadística y probabilística interactiva desarrollada con **PHP**, **Python (Matplotlib)**, **JavaScript** y **CSS**, diseñada para automatizar cálculos, procedimientos paso a paso y representaciones gráficas.

## 🚀 Módulos Implementados

* **Unidad 1 · Estadística Descriptiva:** Tablas de frecuencia (Regla de Sturges, vista estándar de 6 columnas y vista extendida de 13 columnas), gráficos estadísticos (barras, circular, histograma, polígono, línea y ojivas), medidas de tendencia central, posición y dispersión.
* **Unidad 2 · Análisis de Probabilidad:** Reglas de suma y multiplicación, permutaciones, combinaciones, probabilidad clásica, probabilidad condicional y Teorema de Bayes.
* **Unidad 3 · Distribuciones de Probabilidad:** Variables aleatorias discretas y continuas, distribución Binomial, Poisson, Normal estándar, ajuste de curva normal y tamaño de muestra.
* **Configuración y Utilidades:** Selector global de temas visuales, control de precisión decimal (1 a 4 decimales), generador de series numéricas y organizador de datos crudos.

## ⚙️ Requisitos y Ejecución Local

1. Clonar el repositorio dentro de la carpeta pública de tu servidor local (por ejemplo, `htdocs/` en XAMPP o `www/` en Laragon):
   ```bash
   git clone https://github.com
   ```
2. Asegurarse de tener instalado **Python 3** con la librería **Matplotlib**:
   ```bash
   pip install matplotlib
   ```
3. Iniciar Apache en el servidor local y abrir `http://localhost/Calculadora-One-Million/View/index.php` en el navegador.
